Bentist Automation

Privacy Policy

Last updated September 30, 2026

Bentist Automation is a private tool used only by the owner of The Bentist YouTube channel (Dr. Ben Winters) to manage that channel. It is not offered to the public, and nobody else can sign in to it.

Bentist Automation uses YouTube API Services. By using it, users agree to be bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

What it accesses

When the channel owner signs in with Google, the tool uses YouTube API Services and Google APIs to:

  • read the channel's own videos, titles and descriptions (YouTube Data API);
  • read the channel's own analytics and reports, such as views, watch time, impressions and click-through rate (YouTube Analytics API and YouTube Reporting API);
  • read the caption tracks of the channel's own videos, to check that titles and descriptions match what each video says;
  • change the titles and descriptions of the channel's own videos, and in future upload the owner's own videos and set their thumbnails, only as the owner has instructed (see "Consent to changes" below);
  • create and update one Google Sheet in the owner's Google Drive that tracks those title tests. It can reach only files it created itself, not the rest of the Drive.

It does not access other people's accounts, private messages, comments by viewers beyond what YouTube shows publicly, or payment information.

Consent to changes

The tool changes nothing on YouTube unless the channel owner has told it to. The owner turns on each kind of change (for example, a title test that alternates two titles, or a rewrite of a set of descriptions) and can veto or stop any of them at any time. Every change is written to a log with the time, the video, and the old and new text, and titles changed by a test are put back or kept according to its result. The tool never changes a video's privacy or visibility.

Where the data is kept, and for how long

Data is stored on the channel owner's own computer and in the owner's own Google Sheet. Sign-in tokens are stored only on that computer. Nothing is sold, shared with third parties, or used for advertising.

YouTube Analytics and Reporting data (such as views, watch time and impressions) is kept to compare videos over time. Other YouTube data, such as caption text and copies of video titles and descriptions, is deleted or refreshed within 30 days. Some figures shown in the owner's Sheet (for example, watch minutes per 1,000 impressions) are calculated by this tool from YouTube data and are labeled as not coming from YouTube.

The tool does not use cookies and does not store or read information on any viewer's device.

Google API Services User Data Policy

Bentist Automation's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

By using this tool, users are agreeing to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access and data

Access can be revoked at any time on the Google Account third-party connections page or the Google security settings page. After access is revoked, the tool can no longer read or change anything; data it saved is deleted within 7 days of access being revoked from within the tool, and within 30 days of access being revoked through Google's security settings page.
